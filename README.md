# Transformación Digital en Ciencia de Datos

## ¿Por qué es importante?

La Transformación Digital ha cambiado la forma en que las empresas y organizaciones toman decisiones. Gracias a la Ciencia de Datos, podemos analizar grandes cantidades de información y encontrar patrones que antes pasaban desapercibidos.

## Relación con la Ciencia de Datos

Sin la Transformación Digital, los científicos de datos no tendríamos acceso a datos en tiempo real ni a herramientas en la nube para procesarlos. La digitalización de procesos permite que podamos obtener información más rápida y confiable.

## Ejemplos prácticos

- Una tienda en línea que analiza el comportamiento de sus clientes para recomendar productos.
- Un hospital que usa historiales clínicos electrónicos para predecir enfermedades.
- Un banco que revisa transacciones en tiempo real para evitar fraudes.

## Contenido del repositorio

Este repositorio contiene un script en Python que calcula el promedio de una lista de números, como parte de un ejercicio sobre buenas prácticas de programación.
